# Agents for Humans disclosures

## Project history

Artae's submission repository, `Wasseem10/artae-vision`, was created on August
22, 2026. Its root commit is dated August 22, 2026, inside the August 10 through
September 14 hackathon build period. A separate local Git remote named `artae`
points to an older and unrelated repository; none of that remote's branches are
part of this submission history.

## Pre-existing and third-party components

The project uses standard open-source packages and pretrained models rather than
presenting them as newly authored work. Material dependencies include:

- Strands Agents SDK for the incident-coordination agent;
- Ultralytics YOLO object and pose models for visual sensing;
- FastAPI, SQLAlchemy, PostgreSQL, and Pydantic for the control plane;
- Next.js, React, and Supabase client libraries for the web experience; and
- MediaMTX and FFmpeg-compatible video plumbing for live and recorded media.

No source code from the referenced elderly fall-detection GitHub project was
copied into Artae. It was used only as research into pose tracking and temporal
fall-state concepts. Any test footage included in the final submission must be
created by the team or carry a license that permits redistribution.

## AI-assisted development

AI coding assistants were used to help research documentation, implement code,
write tests, and edit product copy. The submitter reviewed and tested the output.
The architecture, product decisions, demonstration, and final submission remain
